# 模拟器接口与验证（第 5 册）

> 本册介绍功能模拟器与周期模拟器的共享接口、确定性约束、错误模型、统计格式及测试接口。

---

## 1. 交付物总览

| 交付物 | 名称 | 输入 | 输出 | 精度 |
|---|---|---|---|---|
| S1 汇编/反汇编器 | `ntas-as` / `ntas-dis` | 02 册文本汇编 / `.ntas` | `.ntas` / 文本 | 二进制精确 |
| S2 功能（软件）模拟器 | `nt-sim` | `.ntas` + 主机 API 调用脚本 + `NutShellGPU.config`（功能段） | 内存映像 + 指令轨迹 | ISA 精确，无时序 |
| S3 周期级（硬件）模拟器 | `nt-cycle` | 同上 + 完整 `NutShellGPU.config` | 内存映像 + 周期统计 + 事件轨迹 | 微结构精确 |
| S4 差分校验工具 | `nt-diff` | S2/S3 输出 | pass/fail 报告 | — |

S2 与 S3 共用 NTAS 解码与功能语义实现，接口位于 `isa` 与 `func`。

参考工程结构（语言不限，接口为契约）：

```
NutShellGPU/
  isa/        解码器、编码向量、指令定义表（02 册）
  func/       S2：warp 栈机、存储数组、host runtime
  timing/     S3：nsm / rf / l1 / noc / l2 / dram 模块，每模块 tick()
  asm/        S1
  driver/     命令队列、launch 描述符、配置解析
  tests/      §8 测试
  tools/      nt-diff、统计汇总
```

## 2. 公共接口（语言无关签名，仅作契约示意）

### 2.1 解码器（S1/S2/S3 共用）

```
Inst decode(u64 word)                      // 失败抛 NtasError(code,pc)
u64  encode(Inst)                          // S1 自测用
struct Inst { op, guard{en,neg,p}, m, kind(R/I/B/M/MI),
              d,a,c, x,y, imm32, imm26, simm16, raw_pc }
```

### 2.2 S2 功能模拟器

```
FuncSim(config_func)
device.malloc(n)->u64 ; free(addr)
memcpy(dst,src,n,kind)                    // H2D/D2H/D2D，立即完成
loadModule(path)->mod
launch(mod, entry, grid, block, smem, args[])   // 按 01 册 ABI
sync()                                     // 跑到 grid 结束
readBytes(addr,n)/writeBytes(...)
setTrace(TraceSpec) / getTrace()
getKernelResult()->{status, exit_code, inst_count, first_error}
```

执行模型（02 册 §10、03 册 §4）：NSM 升序 × warp 槽升序的 RR 大轮；每轮让每个非阻塞 warp 推进一拍（取指恒命中、访存恒完成）；屏障在到达计数满足的同一轮末批量放行。**给定相同输入，S2 的逐指令轨迹必须逐字节确定**（无随机源）。

### 2.3 S3 周期模拟器

```
CycleSim(config_full)
// 主机侧 API 与 S2 相同
run(max_cycles=0) -> Result
Result {
  status, exit_code, cycles,
  mem_dirty_pages(用于和 S2 比对),
  stats(§7), trace_events(可选)
}
setCallback(event, fn)   // 事件：issue, mem_access, replay, bar_arrive/release, dram_cmd...
```

模块契约（每个模块 `tick()` 内只读上周期状态、周期末提交；跨模块队列容量与配置一致）：

| 模块 | 依据 | 关键队列（容量） |
|---|---|---|
| WorkDistributor | 00 §4.1 | CTA 分派环 |
| NSM.Fetch | 03 §3 | I-MSHR(8)、ibuf(2/warp) |
| NSM.Issue | 03 §5 | RR 游标 |
| Scoreboard | 03 §6 | 4/warp |
| Collector | 03 §8 | 8 unit×4 槽 |
| RF | 03 §7 | 4 bank |
| SP/SFU/DP/BRU/LSU | 02 §7/03 §8 | LSU 接收+replay 16 |
| L1D/Shared/PRT/WDB | 04 §1-4 | PRT32、WDB16 |
| NoC | 04 §8 | REQ/RSP 各 4 flit/口 |
| L2 slice ×12 | 04 §9 | MSHR64/slice、写队列 |
| ROP ×6 | 04 §10 | atom cache 2KiB |
| FB/DRAM ×6 | 04 §11-12 | read sorter/store、bank FSM |

确定性：S3 同样不得有非确定源；仲裁所有平局用"编号小者胜"。时序模型必须在**无竞争**时复现 00 册 §5 的名义延迟表（±0）。

## 3. 两模拟器对齐要求

1. **最终内存映像一致**：grid 结束后，global 中被写过的每 32B 块逐字节相同（稀疏比对，只比 touched set）。
2. **未定义行为之外**：同址重叠写决胜（lane 最小）、浮点舍入、整数回绕、NaN 规则完全一致（02 册 §5）。
3. S3 必须提供 `--golden=func_trace` 模式：在每个 kernel 边界和 kernel 内每 N 条全局指令点，把寄存器/掩码快照与 S2 对齐比对（调试钩子，默认关闭）。
4. S3 的时序结果不要求等于任何真实 GPU；但**换用不同语言/作者重写的两个 S3**，在同一配置上周期数必须相同（本规格的仲裁/延迟/队列全部数值化，无自由参数）。

---

## 4. 配置解析契约

- 解析 00 册 §8 的 INI；缺项用默认值；未知键报错而非忽略。
- 派生量（峰值算力、带宽、每 SM CTA 上限组合、L1 组数）由模拟器计算并在启动时回显。
- 合法性断言：smem+l1d==64KiB；l2 总切片数=2×n_mem；burst/sector/line 整除；warp=32 固定；越界数值拒绝启动。
- S2 忽略时序键但必须解析通过（保证同一 config 驱动两个模拟器）。

## 5. 轨迹格式（可选开关，开启后格式固定）

### 5.1 指令轨迹（S2、S3 均可输出）

CSV，每行一拍一条 warp 指令（S2 无 cycle 列，或填逻辑序号）：

```
cycle,sm,cta,warp,pc,opcode,guard_str,exec_mask_hex,rd,ra,rc,dst_value_mask_hex
```

分歧控制流行额外附栈快照：`stack:[{rpc,nextpc,mask}]`（仅在 BRA/BRX/SSY/EXIT 行出现）。

### 5.2 访存轨迹（S3）

```
cycle,sm,warp,pc,space,op,sector_addr,lane_mask,line_hit?0/1,sectors_req,replay_reason
```

DRAM 命令轨迹：`cycle,channel,bank,row,cmd(ACT/PRE/READ/WRITE),row_hit?0/1`。

### 5.3 统计输出

`stats.json`：schema 版本号 + 03 册 §13、04 册 §14 全部计数器（命名蛇形），外加：

```
{ "schema": "NutShellGPU-stats-1",
  "cycles": n, "instructions": n, "ipc": n,
  "simd_efficiency": 0..1, "occupancy_avg": 0..1,
  "dram_effective_bw_GBps": n, "row_buffer_hit_rate": 0..1,
  "power_est_W": n(可选, 附录B) }
```

## 6. 设备错误模型

错误码是 ABI 的一部分；S2/S3 在**同一触发条件**下给出同一码。

| 码 | 触发 |
|---|---|
| ERR_BAD_OPCODE | 保留 OP |
| ERR_BAD_ENCODING | 非法修饰组合/保留特殊寄存器 |
| ERR_UNALIGNED_REG | 64/128 位寄存器号奇对齐 |
| ERR_MISALIGNED_ADDR | 访存自然对齐违例（§04-3） |
| ERR_MISALIGNED_PC | 跳转目标非 8B 对齐 |
| ERR_BAR_ID | id≥16 |
| ERR_BAR_PARTIAL | 部分线程屏障（配置 error 模式） |
| ERR_NO_IPDOM | 分歧 BRA 时栈顶 rpc 为哨兵（漏 SSY） |
| ERR_STACK_OVERFLOW | BRX 使栈深 >32 |
| ERR_ADDR_OUT_OF_RANGE | 地址越界/非法窗口 |
| ERR_LAUNCH | 启动参数违例（00 §8.1 资源约束、维度过限、参数>4KiB） |
| ERR_DEADLOCK | 无可推进 warp 且存在未完成 CTA（自旋锁/SIMT deadlock） |

错误处理：冻结全部执行，Result.status=failed，记录首个错误的 `{code,sm,cta,warp,lane,pc,addr}` 与错误码；之后的 host `ntSync` 返回失败。错误前的存储写入保留（不保证回滚）。

## 7. 性能模型自检（S3 必须通过的解析关系）

1. 无访存、无分歧的无限长指令流：IPC=1（每周期 1 warp 指令），SIMD 效率=1。
2. 全片峰值 FP32 FMA：1.024 GFLOP/周期；64 warps×32 regs 配置下 RF 容量自洽（2048 线程×32=65536）。
3. L1 路径：每次独占命中 30 拍；64 个 warp 每 warp 一条独立命中流可将其完全掩盖（发射不被 L1 卡住）。
4. 单通道带宽 ≤20 GB/s，全片 ≤120 GB/s（统计值不得超过）。
5. 同地址 32 lane shared 读：1 拍分组（广播）；均匀跨步 32 字（lane i→word i）：1 拍；bank 冲突模板 lane i→word (i*2 mod 32)：2 个分组（2 拍+对应 replay 计数 1）。
6. 占用率边界：B=1024、R=32 的 CTA：每 NSM 恰好 2 个 CTA（32 warps×2=64）；R=64 时仅 1 个。
7. DRAM 行命中/缺失命令序列与 tRC/tRAS 约束逐项可在命令轨迹中核验。

## 8. 强制测试集（S1–S4 全部随交付）

| 用例 | 输入内容 | 功能输出 | 时序统计（S3） |
|---|---|---|---|
| `t_decode` | 02 册 §9 等 ≥32 条编码向量 | 编解码逐位一致 | — |
| `t_saxpy` | 01 册 §9 端到端 | y=a·x+y 全数组正确 | IPC、coalescing≈最优、L2 流量 |
| `t_diverge_fig32` | 教材图 3.2/3.3/3.4 | 栈快照序列逐行匹配；x/y/z 计数正确 | 分歧次数=2、最大栈深、SIMD 效率 |
| `t_reduce` | shared + BAR.SYNC 块内归约 | 求和正确（含尾包 warp） | barrier 等待拍数、smem bank |
| `t_sgemm` | 分块矩阵乘（16×16 tile） | C=A·B 逐元素 | 占用率、shared 复用、L1/L2 命中 |
| `t_transpose` | shared 32-bank 冲突正反例 | 转置正确 | 朴素版 replay 数 > 填充版；bank 分组数可手算 |
| `t_atomic_hist` | global ATOM.ADD 直方图 | 直方图精确（不漏加） | ROP 串行化、L2 原子计数 |
| `t_cas_spinlock` | 教材图 3.5 同 warp 锁 | **基线预期：ERR_DEADLOCK（SIMT deadlock）**；S2 需在固定推进轮次内检测 | 死锁检测点与 PC 报告；讲解 3.1.2 |
| `t_vote_shfl` | VOTE/BALLOT/SHFL/S2R | 与标量参考一致 | BRU 吞吐 |
| `t_membar` | 跨 CTA 标志位（一写多读+MEMBAR.GL） | 全部读到终值 | 栅栏等待时 vmem 计数归零 |
| `t_occupancy` | 6 组启动参数（R/B/smem 组合） | 启动成功/失败符合 §00-8.1 | 驻留 CTA 数精确 |
| `t_fp` | FMA 舍入、subnormal、NaN、F64 对 | 与 IEEE 参考逐位 | SP/DP 部件间隔 |
| `t_unaligned` | 跨 sector/对齐违例 | 合法拆分结果正确；非法返回错误码 | sector 数翻倍 |
| `t_brx` | 间接跳转 3 路分歧 | 各路结果正确；栈深度 | 最坏 32 路时 ERR_STACK_OVERFLOW 边界 |
| `t_exit_tail` | 非 32 整数倍线程数 | 尾包 lane 不产生副作用 | mask 永久位检查 |

每个用例提供：`*.ntas`（或汇编）、host 驱动脚本、初始化数据 md5、期望输出 md5、S3 期望统计区间（带宽/IPC 上下限与自检式等式）。

`t_cas_spinlock` 语义说明：基线为栈式 SIMT（pre-Volta 语义）。获得锁的 lane 提前抵达再收敛点后被栈挂起，无法执行释放（教材 3.1.2）；测试要求两个模拟器都检测出 SIMT deadlock 而非给出错误结果。

- 芯片：16 NSM × 64 warp × 32 = 32 768 线程；1.0 GHz；6 通道 GDDR5；120 GB/s；6 GiB；L2 1.5 MiB。
